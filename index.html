왜 만들었나요

문서 형식과 씨름하는 시간을, 수업과 학생에게 돌려드리고 싶었어요.

수업에 쓸 시간을 되찾기

가정통신문 PDF 변환, 첨부 용량 줄이기, 스캔 PDF 정리… 하루에도 몇 번씩 하는 일을 손짓 한 번으로 줄여, 수업 준비와 학생 상담에 시간을 쓰도록.

학생 정보는 내 PC 안에서

생활기록·평가 자료를 인터넷 변환 사이트에 올리지 않아도 돼요. 모든 변환은 선생님 PC 안에서만 이루어져 학생 개인정보를 지켜요.

누구나 쉽게

메뉴를 찾을 필요 없이 끌어다 놓기만 하면 돼요. 디지털 도구가 낯선 선생님도, 과제 형식을 맞춰야 하는 학생도 똑같이 쓸 수 있어요.

쓰는 법은 딱 하나

원본은 그대로, 원본 옆에 새 파일이 생겨요. 여러 파일도 한꺼번에.

1

파일을 끌기 시작

탐색기나 바탕화면에서 바꾸고 싶은 파일을 마우스로 끌어요.

2

끄는 중에 Q

커서 주변에 동그란 메뉴가 펼쳐져요. 마우스는 놓지 마세요.

3

원하는 칸에 놓기

PDF·한글·Word… 칸에 놓으면 끝. 진행 상황은 오른쪽 아래에 보여요.

이런 걸 바꿀 수 있어요

칸마다 넣을 수 있는 파일과 결과

칸넣을 수 있는 파일결과
PDF이미지(여러 장은 한 파일로), 한글, Word, Excel, PPTPDF
이미지이미지, PDF, 한글, Office 문서JPG·PNG·WEBP·BMP, 긴 이미지 한 장
한글PDF, 한글, WordHWP·HWPX
WordPDF, 한글DOCX
ExcelPDF, 한글, Word, PPTXLSX (표를 찾아 시트로)
PPTPDF, 한글, Word, ExcelPPTX (쪽마다 슬라이드)
텍스트PDF, 한글, Office 문서TXT·HTML
용량 줄이기이미지, PDF, 한글같은 형식, 더 작은 파일

화질은 지키고, 용량만 줄여요

원본과 화질 유사도를 비교해서 기준을 넘을 때만 압축해요. 고화질 · 균형 · 최대 3단계.

한글 문서는 글자·표·서식은 그대로 두고 안에 든 그림만 줄여요. 첨부 용량 제한 걱정 끝.

PDF 쪽 편집도 바로

편집 칸에 PDF를 놓으면 쪽을 끌어 순서를 바꾸고, 지우고, 돌릴 수 있어요.

저장은 항상 새 파일로. 원본은 안전해요.

내 손에 맞게

Q 대신 Ctrl+Shift 또는 Alt + 드래그로 바꿀 수 있고, 결과 저장 위치와 품질도 고를 수 있어요.

Alt+`로 화면 캡처 → 바로 클립보드 복사 기능도 들어 있어요.

설치 전에 확인해 주세요

설치도 제거도 내 계정 안에서만, 관리자 권한 없이

설치 방법

  1. 받은 zip 파일의 압축을 풀어요.
  2. 폴더 안의 EDU_Converter.exe를 실행하면 설치 창이 떠요.
  3. 오른쪽 아래 트레이에 보라색 EDU 아이콘이 생기면 준비 끝!
  4. 새 판은 새 zip의 exe만 실행하면 설정은 그대로 두고 업데이트돼요.

필요한 것

  • Windows 10/11 (관리자 권한 필요 없음)
  • 한글 관련 변환: 한컴오피스 한글
  • Word·Excel·PPT 관련 변환: MS Office
  • 열어 둔 한글·Office 창은 건드리지 않고, 직접 놓은 파일만 열어요.
  • 관리자 권한 창 위에서는 Q가 안 돼요 → 트레이 아이콘 클릭으로 고정 메뉴를 쓰세요.
