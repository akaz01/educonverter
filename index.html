EDU_Converter가 Plopp으로 새로 태어났어요

선생님을 위해 만든 앱이었는데, 선생님뿐 아니라 정말 많은 분들이 관심을 보내 주셨어요. 그래서 누구나 쓰기 좋게 이름을 Plopp으로 바꾸고, 화면 녹화·영상 자르기 같은 기능을 늘려 새로 내놓았어요. EDU_Converter에서 쓰던 설정은 그대로 이어져요.

한글·PDF·Word·Excel·PPT·이미지 변환, 화질 지키는 용량 줄이기, PDF 쪽 편집, 화면 녹화와 영상 자르기까지. 프로그램을 찾아 열 필요 없이 파일을 끄는 손길 그대로 끝내는 무료 Windows 앱이에요.

무엇이 새로워졌나요

이름만 바뀐 게 아니에요. 매일 쓰는 일을 더 많이 담았어요.

NEW

화면 녹화

Alt+Shift+`로 영역을 골라 바로 녹화. 컴퓨터 소리와 마이크도 함께 담고, 검은 막대의 [정지]로 끝내면 MP4로 저장돼요.

NEW

영상 자르기·붙이기

필요한 부분만 남기고 여러 영상을 이어 붙여 MP4로. 재생 위치 바와 [여기서 자르기] 버튼 하나면 충분해요.

NEW

새 변환 메뉴

칸에 닿으면 밝게 켜지고, Size 칸에 놓으면 가장 작게·균형·고화질 중에 골라요.

NEW

블랙 · 화이트 테마

설정에서 한 번에 바꿔요. 창과 변환 메뉴가 함께 바뀌어요.

NEW

한국어 · English

설치할 때 언어를 고르고, 나중에 설정에서 언제든 바꿀 수 있어요.

왜 만들었나요

파일 형식과 씨름하는 시간을, 정말 해야 할 일에 돌려드리고 싶었어요.

손짓 한 번으로

PDF로 바꾸기, 첨부 용량 줄이기, 스캔 정리… 하루에도 몇 번씩 하는 일을 끌어다 놓기 한 번으로 줄여요.

내 파일은 내 PC 안에서

인터넷 변환 사이트에 올리지 않아도 돼요. 모든 변환은 내 컴퓨터 안에서만 이루어져 개인정보를 지켜요.

누구나 쉽게

메뉴를 찾을 필요 없이 끌어다 놓기만 하면 돼요. 컴퓨터가 낯선 분도, 매일 문서를 다루는 분도 똑같이.

쓰는 법은 딱 하나

원본은 그대로, 원본 옆에 새 파일이 생겨요. 여러 파일도 한꺼번에.

1

파일을 끌기 시작

탐색기나 바탕화면에서 바꾸고 싶은 파일을 마우스로 끌어요.

2

끄는 중에 Q

커서 주변에 동그란 메뉴가 펼쳐져요. 마우스는 놓지 마세요.

3

원하는 칸에 놓기

칸이 밝게 켜지면 놓아요. 퐁! 진행 상황은 오른쪽 아래에 보여요.

이런 걸 할 수 있어요

칸마다 넣을 수 있는 파일과 결과. ••• 표시 칸은 놓은 뒤 한 번 더 골라요.

자세히 보기

화질은 지키고, 용량만 줄여요

Size 칸에 놓으면 가장 작게 · 균형 · 고화질 중에 골라요. 원본과 화질을 비교해서 기준을 넘을 때만 줄여요.

한글 문서는 글자·표·서식은 그대로 두고 안에 든 그림만 줄여요. 첨부 용량 제한 걱정 끝.

PDF 쪽 편집도 바로

Edit 칸에 PDF를 놓으면 쪽을 끌어 순서를 바꾸고, 지우고, 돌릴 수 있어요. 실수해도 Ctrl+Z.

저장은 항상 새 파일로. 원본은 안전해요.

영상은 자르고 붙여서 MP4로

재생하다 자를 곳에서 [여기서 자르기], 필요 없는 조각은 빼고, 여러 영상은 이어 붙여요.

녹화한 화면도, 휴대폰으로 찍은 영상도 그대로 넣으면 돼요.

무엇을 할지 고르는 시작 창

바탕화면 아이콘을 누르면 PDF 편집, 영상 자르기, 화면 녹화, 화면 캡처, 설정을 바로 열 수 있어요.

Alt+` 화면 캡처는 고르는 순간 클립보드로 복사돼요.

설치 전에 확인해 주세요

설치도 제거도 내 계정 안에서만, 관리자 권한 없이

설치 방법

  1. 받은 zip 파일의 압축을 풀어요.
  2. 폴더 안의 Plopp.exe를 실행하면 설치 창이 떠요.
  3. 맨 위에서 한국어 / ENGLISH를 고르고 [설치]를 눌러요.
  4. 오른쪽 아래 트레이에 검은 Plopp 아이콘이 생기면 준비 끝!

필요한 것

  • Windows 10/11 (관리자 권한 필요 없음)
  • PDF·Word를 한글로 바꿀 때: 한컴오피스 한글
  • Word·Excel·PPT 관련 변환: MS Office
  • 열어 둔 한글·Office 창은 건드리지 않고, 직접 놓은 파일만 열어요.
  • 관리자 권한 창 위에서는 Q가 안 돼요 → 트레이 아이콘 우클릭 → 변환 메뉴 열기 (고정)

새 버전으로 업데이트하는 법

앱에서 "새 버전" 알림을 누르셨다면 여기예요. 지울 필요 없이 덮어쓰면 끝, 설정도 그대로예요.

  1. 바로 아래 Windows용 다운로드 버튼을 눌러 새 zip을 받아요. (가입·로그인 필요 없어요)
  2. 받은 zip 파일의 압축을 풀어요. (파일 우클릭 → 압축 풀기)
  3. 폴더 안의 Plopp.exe를 실행하고 창에서 [설치] 또는 [업데이트]를 눌러요.
  4. 켜져 있던 예전 앱은 알아서 닫히고, 새 버전이 트레이에 다시 떠요. 끝!

EDU_Converter를 쓰고 계셨나요? 그대로 Plopp을 설치하면 돼요. 쓰던 설정은 이어지고, 예전 EDU_Converter는 자동으로 정리돼요.

지금 쓰는 버전은 트레이 아이콘 우클릭 → 정보에서 볼 수 있어요.
